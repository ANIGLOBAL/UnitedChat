# UnitedChat UI

SPA React Router 8 + Tailwind 4, build tĩnh để deploy GitHub Pages.

```powershell
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm run build      # UNITEDCHAT_BASE=/UnitedChat/ nếu deploy dưới subpath
```

Cấu hình runtime: `public/api-config.js` (`window.UNITEDCHAT_CONFIG`). Hướng dẫn đầy đủ ở `../README.md`.
